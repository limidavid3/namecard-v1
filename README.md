# 名片夾（iPhone 名片掃描 App）

拍下名片 → 自動辨識公司、姓名、職稱、電話、分機等資料 → 之後可以用關鍵字搜尋，或依公司分類找名片。

- 所有名片和照片都只存在你的 iPhone 裡，不會上傳到任何伺服器
- 文字辨識在手機上執行，第一次使用需要連網下載約 2 MB 的中文字庫，之後離線也能用

## 檔案說明

| 檔案 | 用途 |
|---|---|
| `index.html` | App 本體（畫面、辨識、資料庫全部在這裡） |
| `manifest.webmanifest` | 讓 iPhone 知道 App 名稱和圖示 |
| `sw.js` | 讓 App 可以離線開啟 |
| `icons/` | App 圖示 |

## 一、放到 GitHub Pages（免費，約 5 分鐘）

1. 到 GitHub 建立新的 repository，例如取名 `cardbox`，設為 **Public**
2. 在 repo 頁面點 **Add file → Upload files**，把這個資料夾裡的所有檔案（包含 `icons` 資料夾）拖進去，按 **Commit changes**
3. 到 **Settings → Pages**，Source 選 **Deploy from a branch**，Branch 選 `main`、資料夾選 `/ (root)`，按 **Save**
4. 等 1～2 分鐘，網址會是：`https://你的帳號.github.io/cardbox/`

> repo 是公開的沒關係：公開的只有程式碼，你的名片資料只存在你自己的手機上。別人打開這個網址，看到的是一個空的名片夾。

## 二、裝到 iPhone

1. 用 **Safari** 打開上面的網址（一定要用 Safari）
2. 點下方的「分享」按鈕 → 「加入主畫面」→「新增」
3. 主畫面會出現「名片夾」圖示，之後都從這裡開啟

## 使用方式

- **掃描**：點「掃描名片」→ 拍照或從相簿選 → 出現紅框，自動框好名片 → 需要的話拖曳四個角微調 → 按「完成」→ 自動辨識並填入欄位 → 檢查後按「儲存」
- **紅框微調**：拖曳四個角或四邊中間的小點；拖曳時會出現放大鏡方便對準。拍歪的名片會自動拉正。沒偵測到時可按「自動偵測」重試，或「整張照片」使用整張圖。之後在「編輯」裡按「調整範圍」也能重新框選
- **背面**：拍完正面後點上方「＋ 拍背面」。背面也會辨識，正面沒有的資料（例如英文 Email、網址）會自動補上；正面已有的不會被覆蓋。之後在「編輯」也可以補拍或移除背面
- **辨識不準時**：
  - 照片是橫的或倒的 → 按「旋轉」，會自動重新辨識
  - 辨識到旁邊的雜物 → 按「調整範圍」把紅框縮小到只框名片
  - 某欄位填錯 → 打開下方「辨識原文」，點那一行文字，選擇要填入哪個欄位
  - 也可以直接點欄位手動修改
- **搜尋**：可以搜姓名、公司、職稱、電話、Email、備註，甚至名片上的任何文字。輸入多個詞（用空白隔開）會找同時符合的名片
- **依公司分類**：切到「依公司分類」，點公司就能看到該公司所有人
- **名片內容頁**：可以直接撥電話（含分機自動轉接）、寄 Email、開地圖，或加入手機通訊錄

## 備份（重要）

資料只存在這支手機的 App 裡。換手機或刪除 App 前，請先備份：

- 右上角「⋯」→「匯出備份檔（含照片）」→ 存到「檔案」或 iCloud Drive
- 新手機裝好 App 後 →「⋯」→「匯入備份檔」
- 「匯出 Excel 清單（CSV）」可以在電腦上用 Excel 打開

## 之後要更新 App

修改檔案後重新上傳到 GitHub，並把 `sw.js` 第 3 行的版本號改成新的號碼（例如 `cardbox-v2` → `cardbox-v3`），手機下次開啟時就會抓到新版。名片資料不受影響。
